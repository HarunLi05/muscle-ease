# 松一松 · 肌肉放松指南

一个点开即用的中文肌肉放松工具。访客无需注册、登录、付款或填写个人信息。

## 功能

- 正面和背面人体肌肉示意图，点击图形或部位名称即可切换。
- 13 个肌肉区域，每处提供两个温和动作、步骤和提示。
- 单次动作计时，支持暂停、继续和再做一组。
- 适配电脑和手机。

## 使用与隐私

所有交互都在访客的浏览器中运行，无后端、账号、数据库、广告或统计脚本，不收集或保存个人信息。字体与人体图形不依赖第三方 CDN。只有用户主动点击参考资料链接时才会跳转到外部网站。

GitHub Pages 会按照 GitHub 自己的服务政策处理网站访问日志；本项目本身不添加追踪工具。

页面提供日常肌肉紧绷的放松参考，不能据此判断疼痛病因，不用于个体化康复处方。

## 免费发布到 GitHub Pages

1. 创建一个 Public 公开仓库，将本目录中的文件上传到仓库根目录。
2. 进入仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 **main** 分支和 **/(root)** 文件夹，点击 **Save**。
5. 等待 Pages 部署成功，将设置页显示的网站链接发给其他人。

如果仓库是 `HarunLi05/muscle-ease`，上线后网址通常为 `https://harunli05.github.io/muscle-ease/`。请以上线后 Pages 设置页显示的实际地址为准。

访客直接打开网站即可使用，不需要 GitHub 账号。发布者配置网站时需要登录 GitHub。

## 本地打开

直接双击 `index.html`；也可以在本目录运行：

```sh
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## 文件

- `index.html`：页面结构。
- `style.css`：样式与响应式布局。
- `app.js`：肌肉示意、动作内容与计时器。
- `.nojekyll`：按普通静态文件发布，无需构建。
